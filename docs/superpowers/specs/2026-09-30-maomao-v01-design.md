# 毛毛桌宠 V0.1 设计规格

## 目标

在 Windows 桌面上跑起一只「会动」的毛毛：透明置顶窗口 + 序列帧动画 + 点击/拖拽 + 完整右键菜单（多数占位）。

## 技术

- C# / WPF / .NET 8 / Visual Studio 2022 编译 exe
- 轻量单窗口；`Assets/Pet/{state}/001.png…` 按帧播放；无帧时用程序绘制占位图

## 窗口

- 无边框、透明、始终置顶、不进任务栏
- 约 200×200，启动于屏幕右下角偏上

## 状态机

`Idle` / `Walk` / `Sleep` / `Drag` / `Click`

- 空闲时随机：发呆、短距离走动、睡觉
- 拖拽优先；松手回 Idle
- 点击进入 Click，连点升级文案后回 Idle

## 菜单（V0.1）

互动 / 喂食 / 摸摸 / 游戏 / 聊天 / 换装 / 房间 / 日记 / 成就 / 背包 / 设置 / 退出  
未实现项显示「马上就来～」占位提示。

## 明确不做（本版）

AI、养成数值持久化、房间/换装实装、小游戏、鼠标穿透、系统托盘。
